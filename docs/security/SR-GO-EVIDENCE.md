(offline, vendored) and at least one failed; every mutation was reverted. Tests added for a row are in the
`security_a_test.go`, `security_b_test.go` and `security_c_test.go` files of the package named. The base is `5cb35d2`
(tag `python-final`). Some new engine tests replay recorded inputs and answers of the Python tests, captured at that commit.
