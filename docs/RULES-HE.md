# ספר החוקים — סיכום בעברית

סיכום לליאו של [RULES.md](RULES.md) (המקור באנגלית; כל כלל מופיע שם עם מקורו ותאריך).

- **היקף המוצר:** ספריית Go לזיהוי פרוטוקולים ואפליקציות, מוטמעת ב-Culvert. הספרייה לא מבצעת I/O, והמארח אחראי על סוקטים, TLS, מדיניות והעברה. בתוך Culvert הגלאי מזהה בלבד ולא אוכף.
- **ראיות, לא זהות:** SNI, ALPN, פורט וטביעות אצבע הם ראיות ולא זהות מאומתת. הקלט הוא IPv4 וקלט סינתטי בלבד. לא מבצעים push, PR, merge או release ל-Culvert המקורי.
- **Python:** הוא הייחוס המוקפא. שינוי בו מותר רק ברשימת החריגים ב-migration/STATUS.md. סוגי פרוטוקולים חדשים ייבנו ב-Go בלבד. השאלה אם לפרוש את Python לגמרי פתוחה, וההחלטה שלך.
- **מיזוגים:** PR קטנים. מיזוג ל-main דורש את הלחיצה שלך, חוץ מכלל האוטו-מרג' מ-22.11: קבצי Markdown בלבד או נתוני research/ בלבד, עם בדיקת `ci gate` ירוקה. רק merge commits, בלי rebase ובלי force-push. הקומיטים נכתבים על שם Lee Nadav.
- **אבטחה:** P0/P1 הן קריטיות והן חוסמות מיזוג. P2 גבוהה, P3 נמוכה. תיקון חייב מבחן שנכשל קודם. לא מחלישים בדיקות.
- **נקודות פתוחות לכריעה שלך:** מי מאשר מיזוג בלי לחיצה (CLAUDE.md סותר את כלל 22.11); איזו רשימת חריגי Python היא הסמכותית (AGENTS.md קצרה מ-STATUS.md); האם GitHub משמש להודעות (AGENTS.md משתמש בו לתור Codex); ומה מצב השפה והתלויות של המוצר (המסמכים עדיין מתארים Python 3.9).
- **הוספת כלל:** חוקים חדשים נכנסים דרך ההערה בנושא "חוקי הפרויקט — עדכונים" עם תאריך ושם המאשר, ו-Docs מאחד אותם ב-PR אחד לכל קבוצה.
