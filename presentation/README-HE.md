# Protocol Observatory — הדגמה למנכ״ל

ממשק מקומי שפועל עם עותק של המנוע בענף `claude/engine-next`, גרסה **0.65.0**.
קומיט המקור: `08274cbb5cfc8eab0abdef9a3bace027e8ef943b`.
העותק עודכן ב־6 בנובמבר 2026. שינויים עתידיים בענף אינם נכנסים אליו אוטומטית.

## פתיחה

נוסף **Decryption & App-ID** לפענוח TLS 1.3 עם מפתחות ולזיהוי אפליקציה פנימית.
באותה לשונית אפשר גם להפעיל **Start capture + decryption** ללכידה ופענוח חיים יחד, עם קובץ מפתחות מתעדכן.
ראה [DECRYPTION.md](DECRYPTION.md) לשימוש, גבולות ודמו WebDAV מוצפן.

לחץ פעמיים על `Start Protocol Observatory.command`. הדפדפן ייפתח בכתובת מקומית,
בדרך כלל http://127.0.0.1:8765. השאר את חלון Terminal פתוח בזמן ההצגה.
לסיום שרת שהופעל מהקובץ, לחץ Ctrl+C בחלון הזה.

אם macOS לא מאפשר פתיחה בלחיצה כפולה, אפשר להריץ מתוך התיקייה:

```sh
bash 'Start Protocol Observatory.command'
```

המפעיל משתמש ב־Python המצורף ל־Codex כשהוא זמין, אחרת ב־Python של המחשב.
אין צורך ב־npm או בשירות ענן. פענוח TLS דורש את cryptography כמפורט ב־DECRYPTION.md;
היא כבר מותקנת ב־Python המצורף ל־Codex במחשב הזה. הקוד תואם Python 3.9 ומעלה.

## סיפור הצגה של שלוש דקות

1. פתח את Overview: מוצגים נתונים שהמנוע הפיק מ־18 סשנים סינתטיים. 15 מזוהים, שלושה נשארים לא מוכרעים. זה אינו שיעור דיוק על תעבורת לקוח.
2. לחץ Run demonstration: הרשומות יופיעו בהדרגה. ההנפשה מציגה תוצאות של ניתוח מקומי שהושלם; היא אינה לכידה חיה.
3. לחץ על הסיפור הראשון: SSH מזוהה על פורט 443. פתח את הראיות כדי להראות שההחלטה מבוססת על תוכן, ושימוש בפורט חריג מסומן בנפרד.
4. לחץ על הסיפור השני: HTTP CONNECT עובר ל־TLS. ציר האירועים מציג את המעבר המבני והפרטים שנצפו. אין פענוח תוכן HTTPS.
5. לחץ על הסיפור השלישי: המנוע משאיר מידע לא מספיק כלא מזוהה. הוא אינו מכריח זיהוי חיובי.
6. פתח Protocol library: הרשימה נקראת ישירות מקטלוג המנוע, עם תחום הכיסוי והפרוטוקולים שדורשים hint.

## לכידה חיה

ב־Live traffic בחר ממשק רשת (למשל en0 עבור Wi-Fi, לפי המחשב), משך לכידה ולחץ Start live capture.
Stop capture עוצר את הלכידה. אין שמירת payload לקובץ ואין פענוח HTTPS.
אירועי הזיהוי מתעדכנים פעם בשנייה, כולל שינויי פרוטוקול ואירועי ביטול זיהוי.
Session explorer מציג פסקי דין סופיים בעת FIN/RST, פקיעת חיבור או עצירה — לא רשימה מלאה של חיבורים פעילים.
מוני TCP/UDP פעילים מופיעים מעליו. נתוני אובדן פאקטות מתקבלים מ־tcpdump בדרך כלל בעצירה;
עד אז מופיע במפורש שהנתון עדיין לא דווח.

ברירת המחדל היא שתי דקות, עד עשר דקות או 100,000 פאקטות. אם הדפדפן מפסיק לבצע polling,
הלכידה נעצרת בתוך כ־30 שניות. נשמרים בזיכרון רק 200 אירועים ו־500 פסקי דין אחרונים;
המנוע מוגבל ל־128 חיבורי TCP ול־16 KiB איחוד לכל כיוון. תעבורת השרת המקומי בפורטים 8765–8775 מוחרגת.
תהליך Python נשאר עם ההרשאות הרגילות. אם tcpdump אינו מורשה לגשת לממשק,
מוצגת השגיאה — הממשק אינו מפעיל sudo ואינו משנה הרשאות מערכת.

בדיקה ייעודית מקומית בלבד: `python3 -B live_smoke_check.py` מייצרת HTTP ב־127.0.0.1:45991,
לוכדת רק את הפורט הזה ומוודאת זיהוי ועצירה. בחירה ב־Local test בממשק מגבילה לאותו פורט;
הבחירה אינה מייצרת תעבורה בעצמה. הבדיקה עברה עם 12 פאקטות, סשן HTTP אחד ואפס kernel drops.

## קובצי capture

Analyze capture מקבל PCAP או PCAPNG. אפשר להשתמש ב־`engine/sample.pcap` כדוגמה מקומית.
המגבלות: 8 MB, עד 20,000 פריימים, 500 סשנים, 4,000 אירועי זיהוי ו־25 שניות לעובד.
העיבוד זמני במחשב; הקובץ הזמני נמחק בסיום. ניתוח קובץ אינו מפעיל לכידה חיה ואינו שולח נתונים לשירות חיצוני.
Export report מוריד JSON עם תוצאות, ראיות, פרטי מקור ומדידות.

סינון: חיפוש לפי IP, אפליקציה או פרוטוקול, TCP/UDP, זיהויים או מקרים לא מוכרעים.
לחיצה על שורה פותחת פרטים. Escape סוגר את החלונית.

## איך לפרש את המספרים

- זמן העיבוד הוא זמן ניתוח הקובץ המקומי, כולל פענוח ואיחוד מקטעים. הוא אינו latency של SWG, benchmark מבוקר או זמן העברה בפרוקסי.
- Risk signals הם סימנים מייעצים. ציון הסיכון 1–5 מגיע מקטלוג האפליקציות; אף אחד מהם אינו הוכחה להתקפה או לחסימה.
- תעבורת ההדגמה מיוצרת מקומית ולא נשלחת ברשת. דוגמאות TCP כוללות מקטעים שהגיעו שלא לפי הסדר.
- הממשק משתמש ב־IPv4 בלבד. פענוח TLS זמין בניתוח קובץ וגם במסלול Live capture + decryption עם key log. לכידה רגילה אינה מפענחת; אין חיבור לפרוקסי או אכיפה.
- פרטי הראיות עשויים להכיל שמות שנטענו בפרוטוקול, כמו SNI/Host. לא נטענת זהות אפליקציה מאומתת.

## קבצים

- `web/` — ממשק HTML/CSS/JavaScript עצמאי, ללא תלויות חיצוניות.
- `server.py` — שרת מקומי ומתאם למנוע; ניתוח קובץ בתהליך מוגבל בזמן.
- `engine/` — עותק מקור v0.65; לא בוצעו שינויים בלוגיקת המנוע.
- `SOURCE.json` — קומיט המקור ו־Git blob hashes של קובצי המקור שהורדו.
- `tests/` — בדיקות המתאם וההתאמה לפלט המקורי של המנוע.

בדיקות הממשק/מתאם:

```sh
python3 -B -m unittest discover -s tests -v
```

בדיקות המנוע:

```sh
cd engine
python3 -B -m unittest discover -q
```

ב־Python 3.12.14 המצורף ל־Codex עברו 655 בדיקות המנוע. ב־Python 3.9.6 של macOS,
ספריית TLS המקומית אינה מציעה TLS 1.3 בשני תרחישי בדיקה שמצפים לכך; זו מגבלה
של בדיקות המקור בסביבה הזאת, ולא שינוי של הממשק. ההפעלה המומלצת היא דרך הקובץ המצורף.
