Answers Hermes on PRO-505 (SEC-CHILD-4): `matchPattern` in `go/internal/childapp/childapp.go` split the whole path for every pattern, so a 4 KiB path of 2,048 segments cost about 140 µs and 133 KB on the embedded Graph rules and 8.4 ms and 8.5 MB against 256 patterns on one host (local benchmarks, go1.27.4). The path is now split once per request, lazily and into at most 33 parts; a pattern compares the segment count first; `canonicalPath` finds dot segments without splitting; and the loader refuses more than `MaxPatternsPerHost` (256) path patterns under one host or host suffix (the embedded data peaks at 21, on `graph.microsoft.com`). Both cases now cost about 10 µs and under 1 KB (`BenchmarkClassifyGraphLongPath`, `BenchmarkClassifyPatternCapLongPath`). Matching is unchanged: randomized tests compare the new matcher with the old one (32,000 pairs) and the dot-segment scan with the old split (20,000 paths); `TestPatternWorkSplitsOncePerRequest` pins at most one split per request. Docs: `docs/CHILD-APPS.md`.
