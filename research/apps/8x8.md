## 1. What it is

8x8 Work (X Series) is a cloud phone, contact-centre and meetings service; 8x8 Meet (`8x8.vc`) is its Jitsi-based video
service. Wavecell is 8x8's CPaaS (messaging API) business.

## 2. Transport and ports

"All 8x8 services are deployed within the IP address spaces listed in this document and identified by one of the domains
listed in this document. Outbound requests made to these ranges on port 80 (HTTP) will be redirected to port 443 (HTTPS)"
[X8]. Proxies are supported only for TCP 80/443; audio and video should bypass them. Ports table [X8]: provisioning TCP 80,
443; device SIPS TCP 5443; LDAPS TCP 636; NTP 123; DNS 53; device SIP UDP 5199, 5299, 5399; SIP activation UDP 5060;
softphone HTTPS TCP 443, SIPS TCP 5401, SIP TCP 5199; SRTP UDP 24000-30999, 38000-44999, 50000-65535; WebRTC UDP
20000-40000; 8x8 Meet TCP 443, UDP/TCP 443, UDP 10000; STUN/TURN UDP 3478-3480. The subnet table (also offered as a signed
JSON with one-hour links) was not copied.

## 4. Encrypted-traffic caveats

`callstats.io` is listed as 8x8-owned, but whether it still serves other companies' WebRTC monitoring is `UNVERIFIED`
(no primary page on it was read). It is left out, conservatively: if other products embed it, it would name 8x8 for unrelated
calls (decision 4). The deprecated domains are
left out (no current service). `jitsi.net` is 8x8's Jitsi infrastructure; the community `meet.jit.si` stays `jitsi-meet`.
SIP, SRTP and WebRTC media are UDP or non-TLS and off the observed path in this phase.
